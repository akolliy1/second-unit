Role

An entry page for choosing how the console words its findings. It is the only screen in the product whose content is a choice, which is why it is a page rather than a modal.

What this is not

Not authentication. There are no accounts, no credentials, and no access control anywhere in this prototype — a stranger with the URL sees everything, by design. Choosing a lens changes wording and level of detail, never which data is fetched or what the agent is allowed to do.

The real permission boundary is elsewhere and is not ours: the Grafana service-account token carries annotations:write, dashboards:write and alert.rules:write, and Grafana enforces it server-side. App-level roles on top of that would be decoration over someone else's ACL.

What clicking a card does

  • Writes the choice to localStorage["second-unit:persona"] — the value is one of td, supervisor, producer
  • Navigates to /?persona=…, so the choice also travels in the URL

Both, because either alone has a hole: storage throws in a private window or with site data blocked, and a URL parameter is forgotten on the next visit. The card is a plain link, so it still works with JavaScript broken — the handler only adds the remembered value.

?persona= on any page overrides the remembered choice for that visit, which is what makes deep links for a demo reliable.

The farm summary line

One GET /api/fleet on load. Same endpoint, same deterministic sweep as the Overview's triage strip: two Prometheus instant queries and division in Python, no model in the path. It reports the number of shots in flight, how many are forecast to miss the published review deadline, and the worst one by slip.

It is fetched once rather than polled — this page is somewhere a judge spends seconds, and the Overview owns the live view. If the sweep fails, the reason is printed here; if it returns no shots, the line says the seeder is probably not running rather than implying a quiet farm.
